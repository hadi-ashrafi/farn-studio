# FARN Studio — وب‌سایت

سایت استاتیک (HTML / CSS / JS خالص)، دو زبانه (انگلیسی + فارسی راست‌چین).

## اجرا
```bash
python3 -m http.server 5173 --directory website
```
بعد `http://localhost:5173` را باز کنید. (`?lang=fa` یا `?lang=en` زبان را مستقیم انتخاب می‌کند.)

## چه چیزی کجاست
| فایل | محتوا |
|---|---|
| `js/config.js` | **شماره تماس، ایمیل، اینستاگرام، یوتیوب، ویدیوها، یوزرنیم گیت‌هاب، نمونه‌کارها، پلن‌ها و قیمت‌ها** |
| `js/i18n.js` | همهٔ متن‌های سایت به انگلیسی و فارسی |
| `css/style.css` | رنگ‌ها (بالای فایل در `:root`، رنگ اصلی `--accent`) و همهٔ استایل‌ها |
| `js/main.js` | انیمیشن‌ها، نمایشگر زندهٔ پروژه‌ها، فرم تماس |
| `work/` | دو دموی نمونه که در نمایشگر زنده باز می‌شوند |

## اضافه کردن نمونه‌کار وب
در `config.js` داخل `projects` یکی از این‌ها را بدهید:
- سایت روی سرور: `live: "https://example.com"`
- گیت‌هاب با GitHub Pages: `github: { repo: "my-repo", pages: true }`
- فقط فرانت روی گیت‌هاب (بدون Pages): `github: { repo: "my-repo", branch: "main", path: "index.html" }`

نکته: بعضی سایت‌ها اجازهٔ نمایش داخل iframe نمی‌دهند؛ در آن صورت دکمهٔ «باز کردن در تب جدید» در نمایشگر هست.

## کارهای بعدی
- جایگزینی ایمیل/اینستاگرام/یوتیوب واقعی در `config.js`
- نمونه‌کارهای واقعی و قیمت‌های نهایی
- فرم تماس فعلاً برنامهٔ ایمیل را باز می‌کند؛ بعداً به بک‌اند یا سرویس فرم وصل شود

## آیکون‌ها
فاوآیکن (تب مرورگر و نتایج جستجو): نماد سفید و نارنجی روی کاشی مشکی — `assets/brand/favicon.*`
آیکون وب‌اپ (افزودن به صفحهٔ اصلی): نماد سفید و نارنجی روی پس‌زمینهٔ مشکی — `icon-192/512`، `maskable-512`، `apple-touch-icon` و `site.webmanifest`
